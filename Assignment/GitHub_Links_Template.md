## How to Get Your GitHub Links

1. **If your repo is already on GitHub:**
   - Go to your repository on GitHub
   - Navigate to the file
   - Click "Raw" button for raw link, or copy URL from address bar for view link

2. **If your repo is not on GitHub yet:**
   - Push your code to GitHub
   - Then use the links above (replace YOUR_USERNAME and YOUR_REPO)

3. **Quick Format:**
   - View: `https://github.com/USERNAME/REPO/blob/BRANCH/PATH/TO/FILE`
   - Raw: `https://github.com/USERNAME/REPO/raw/BRANCH/PATH/TO/FILE`
   - Usually `main` or `master` for branch name
