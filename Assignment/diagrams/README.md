# Mermaid Diagram Files

This folder contains all Mermaid diagram code extracted from the assignment documentation for easy copying and use.

## How to Use These Files

### Option 1: View Online (Recommended)
1. Go to https://mermaid.live/
2. Open one of the `.mmd` files
3. Copy the contents
4. Paste into the Mermaid Live Editor
5. Export as PNG or SVG

### Option 2: Use in Markdown
- These diagrams will render automatically in:
  - GitHub (when viewing `.md` files)
  - VS Code (with Mermaid extension)
  - Many markdown viewers

### Option 3: Use in Other Tools
- Copy the Mermaid code
- Import into tools that support Mermaid:
  - Draw.io (diagrams.net) - has Mermaid import
  - Notion
  - Obsidian
  - Many other documentation tools

## Quick Start

1. **To view a diagram:**
   - Open the `.mmd` file
   - Copy all contents
   - Paste into https://mermaid.live/
   - View and export

2. **To edit a diagram:**
   - Use Mermaid Live Editor
   - Or edit the `.mmd` file directly
   - Mermaid syntax is intuitive and well-documented

3. **To include in documentation:**
   - Wrap the code in markdown code blocks:
     ````markdown
     ```mermaid
     [paste diagram code here]
     ```
     ````
