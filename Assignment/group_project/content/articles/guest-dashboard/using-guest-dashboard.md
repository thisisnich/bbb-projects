# Using the Guest Dashboard

The **Guest Dashboard** shows real-time court status, crowd levels, and environment data. You can use it without creating an account or logging in.

## What you see

- **Court / crowd status:** Which courts are empty, light, normal, busy, or full, plus people count
- **Environment:** Temperature, humidity, UV index, air quality (VOC), and whether conditions are playable
- **Charts:** Short-term trends for crowd and environment (updates in real time)
- **Map:** Court locations and status on a map (if the map page is enabled)

## How to open it

- Go to the main URL (e.g. `http://<server>:5000`) or the guest dashboard link.
- If the site shows a login page, look for **“Continue as guest”** or open the direct guest dashboard URL (e.g. `/guest` or as configured).

## Tips

- **Refresh:** Data updates over the connection; if something looks stuck, refresh the page.
- **Time:** Timestamps are usually in your local time; the server stores UTC.
- **Multiple courts:** Switch or scroll between courts if your facility has more than one.

For step-by-step “before you visit” use, see [Check Court Status Before You Visit](check-court-status).
