# Check Court Status Before You Visit

Avoid wasted trips by checking court status on the Guest Dashboard or court displays before you leave.

## Steps

1. **Open the dashboard**  
   Go to the main site or Guest Dashboard (no login needed).

2. **Find your court**  
   Look at the court list or map. Each court shows a status: Empty, Light, Normal, Busy, or Full.

3. **Check people count**  
   Use the number shown (e.g. “3 people”) to see how crowded it is.

4. **Check environment (optional)**  
   Look at temperature, UV, and “Playable” to see if conditions are suitable (e.g. heat, rain warnings).

5. **Decide**  
   If the court is full or conditions are bad, you can choose another time or court.

## On-site displays

At the facility, **Module 5 court displays** show the same status. You can also check there when you arrive.

## If data looks wrong

- Wait a few seconds; data updates in real time.
- If it’s stuck, see [Common Issues and Troubleshooting](/knowledge-base) for refresh and connection tips.
