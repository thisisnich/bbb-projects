# Alerts and Logs on the Personnel Dashboard

Personnel can see **alerts** (incidents that need attention) and an **activity log** (events from modules and the server). Use these to monitor the facility and troubleshoot issues.

## Activity log

The log shows events in time order, for example:

- Module connections and disconnections
- Crowd, environment, and feedback data received
- Errors or connection problems
- Optional: security-related events

**How to use it:**

- **Scroll or filter** by time or type to find a specific event.
- **Timestamps** are usually shown in your local time (stored as UTC on the server).
- If a module stops sending data, check the log for the last “data received” or “disconnect” for that module.

## Alerts / incidents

Alerts are generated when something needs attention, for example:

- Very high or low sensor readings (e.g. temperature, crowd)
- Security or safety triggers (if configured)
- Module offline or repeated failures
- Maintenance reports from the Feedback Kiosk (Module 3)

**What to do:**

- Review new alerts on the Personnel Dashboard (and Security Dashboard if you have access).
- Assign or escalate as per your facility’s procedures.
- Use the activity log to see what happened before and after an alert.

## Security Dashboard

For critical security alerts and a dedicated view, use the **Security Dashboard** (Module 4). See [Security Dashboard and Alerts](/knowledge-base) for details.
