# Personnel Dashboard Overview

The **Personnel Dashboard** is for staff and security. After you [log in](login), you get access to alerts, activity logs, and full analytics that guests do not see.

## What’s different from the Guest Dashboard

| Feature           | Guest              | Personnel (after login)      |
|------------------|--------------------|------------------------------|
| Court status      | Yes                | Yes                          |
| Environment       | Yes                | Yes                          |
| Alerts & incidents| No                 | Yes                          |
| Activity / event log | Limited or none | Full                         |
| Security dashboard| No                 | Yes (if role allowed)        |
| Historical / charts | Basic            | Fuller history and breakdown |

## Main sections

- **Overview:** Summary of courts, crowd, and environment.
- **Alerts / incidents:** Warnings and events that need attention (see [Alerts and Logs](alerts-and-logs)).
- **Activity log:** Chronological list of module events, connections, and data.
- **Charts:** Crowd and environment over time, per court or facility-wide.
- **Security:** Link or integration with the Security Dashboard for critical alerts (see [Security Dashboard and Alerts](/knowledge-base)).

## How to access

1. Go to the login page.
2. Enter your personnel username and password.
3. After login, you are redirected to the Personnel Dashboard.

If you don’t have an account, contact your facility admin. For login issues, see [Troubleshooting Login](/knowledge-base).
