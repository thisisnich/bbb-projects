## What’s the difference between Guest and Personnel dashboards?

The Guest Dashboard shows court status, crowd levels, and environment to everyone (no login). The Personnel Dashboard adds alerts, the full activity log, and access to the Security Dashboard. Only logged-in staff/security can use the Personnel view.

## Where is court status shown?

Court status (empty/light/normal/busy/full and people count) appears on the Guest Dashboard, the Personnel Dashboard, the map page (if enabled), and on the on-site court displays (Module 5). Data is the same; only the view and extra features (e.g. alerts) differ.

## Why isn’t the dashboard updating?

Data is pushed in real time. If numbers look stuck, refresh the page once. If it keeps happening, the server or a module may be down — personnel can check the activity log for “module connected” and “data received” for each court. See [Common Issues and Troubleshooting](/knowledge-base).
