# Click Board Slot Configuration

This document maps each click board slot to its corresponding BeagleBone GPIO pins.

## Slot Assignments

| Slot | Pin Assignment |
|------|----------------|
| 1 | P9_15 (GPIO Input) |
| 2 | P9_41 (GPIO Input), P9_23 (GPIO Output) |
| 3 | P8_19 (PWM) |
| 4 | P8_10 (GPIO Input) |
